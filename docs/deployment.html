Deployment Guide

MyCLI supports deploying to multiple cloud providers and PaaS platforms.

Supported Providers

PaaS (Platform as a Service)

  • Railway — my deploy setup --provider railway
  • Fly.io — my deploy setup --provider fly
  • Render — my deploy setup --provider render
  • Vercel — my deploy setup --provider vercel
  • Netlify — my deploy setup --provider netlify
  • Heroku — my deploy setup --provider heroku
  • DigitalOcean App Platform — my deploy setup --provider digitalocean

IaaS (via Terraform)

  • AWS (ECS Fargate, Lambda, EKS, CloudFront) — my deploy terraform --provider aws
  • Azure (AKS, App Service, Container Instances) — my deploy terraform --provider azure
  • Google Cloud (Cloud Run, GKE, Cloud Functions) — my deploy terraform --provider gcp
  • DigitalOcean (Droplets, Kubernetes) — my deploy terraform --provider digitalocean

Quick Start

# PaaS deploy
my deploy setup --provider railway
my deploy push --provider railway

# IaaS deploy
my add terraform --provider aws
my deploy terraform plan --provider aws
my deploy terraform apply --provider aws --yes

Secrets Management

my deploy secrets sync --provider railway
my deploy secrets sync --provider aws-sm --sdk
my deploy secrets sync --provider vault
my deploy secrets validate --provider railway

Lifecycle Commands

my deploy status --provider railway
my deploy logs --provider fly
my deploy rollback --provider fly --dry-run
my deploy destroy --provider aws --dry-run

SDK Deploy Mode

Set --sdk to use cloud provider SDKs directly (AWS ECS/Lambda, GCP Cloud Run, Azure Container Instances) without requiring Terraform or CLI tools locally:

my deploy push --provider aws --sdk --image ecr.aws/app:latest
my deploy push --provider gcp --sdk --image gcr.io/proj/app:latest
