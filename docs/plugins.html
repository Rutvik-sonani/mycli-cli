CLI commands

my plugin search docker
my plugin install @mycli-cli/docker
my plugin install digitalocean
my plugin install azure-pipelines
my plugin list
my plugin create @mycli-cli/plugin-billing
my plugin publish ./plugins/community/my-plugin

Community example

See plugins/community/hello-mycli for a minimal community plugin built with @mycli-cli/plugin-sdk.

Authoring

1. my plugin create @mycli-cli/plugin-<name> 2. Implement install(), optional commands(), hooks(), dependencies() 3. Test locally with my plugin install ./plugins/community/<name> --path 4. Publish with my plugin publish

Full reference: PLUGIN_GUIDE.md and MARKETPLACE_GUIDE.md.
