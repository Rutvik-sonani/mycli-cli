Ecommerce preset

Create a shop-ready API with products, cart, orders, auth, RBAC, swagger, docker, and Stripe payment.

my create ecommerce --yes
# or
my create my-shop --preset ecommerce --yes
# retrofit an existing project:
my add ecommerce

ORM support

| ORM | Behavior | |-----|----------| | prisma | Patches prisma/schema.prisma + Prisma repositories | | drizzle | Appends tables to src/database/schema.ts + Drizzle repositories | | typeorm | Writes src/database/entities/ecommerce.entities.ts + TypeORM repositories | | mongoose | Writes src/database/models/ecommerce.models.ts + Mongoose repositories | | sequelize | Writes Sequelize models + repositories | | mikroorm | Writes MikroORM entities + repositories | | none | In-memory repositories (swap by recreating with an ORM) |

my create shop --preset ecommerce --orm typeorm --database mysql --yes

Generated modules

| Module | Path | |--------|------| | Products | src/modules/products/ | | Cart | src/modules/cart/ | | Orders | src/modules/orders/ | | Register | src/modules/ecommerce.register.ts → wired into src/routes/features.ts | | Payment | src/services/payment/ (Stripe by default) |

Routes

After create, registerEcommerceRoutes(app) is registered automatically alongside auth/payment.
