# MyCLI

**Laravel Artisan for Node.js** — create, generate, and deploy production Node.js apps from the CLI.

> This public repository hosts the **product landing page and documentation site** only.  
> The full MyCLI platform monorepo is **private** and is not published here.

## Install

```bash
npm i -g @mycli-cli/cli
# or
pnpm add -g @mycli-cli/cli
```

```bash
my create
my make module user
my add auth
my doctor
```
